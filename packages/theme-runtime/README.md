# @oktis-works/theme-runtime

The theme runtime discovers, validates, and renders compiled React/Solid theme
artifacts.

## Responsibilities

- validate manifest compatibility and `render.apiVersion: 2`;
- resolve inheritance only through same-engine logical keys;
- validate `dist/theme-build.json`, build IDs, and theme-relative assets;
- import the server artifact after validation;
- invoke `render(key, data, context, sdk)`;
- reject invalid themes instead of rendering a legacy fallback.

The runtime has no string-template parser and no React or Solid dependency.

## Logical keys

Routing uses logical keys such as `home`, `index`, `single`, `page`,
`archive`, `404`, and specific keys derived from content type and slug.
The compiled artifact declares its available keys.

## Build schema

The v1 artifact uses schema version 2 and SDK API version 2. It is generated by
`@oktis-works/theme-builder` and consumed by the runtime.
